Start a new app

The console does not create apps any more: it writes v2 records, and v2 has no create path yet. Make the app outside the console, then migrate its staging instance to v2.

  1. make app-repo NAME=<app> TYPE=<type> STACK=<stack> creates the public repository and prints the app-new line for its first image.
  2. make app-new NAME=<app> ARGS="--from-repo samclement/<app> --env staging --team <team> --image <image>" writes v1's staging records.
  3. swhurl-v2 migrate --snapshot <snapshot> --app <app> --env staging --profile v2/testdata/profile.json --source-repository samclement/<app> --source-commit <full commit> --out . writes v2's records and compiled files.
  4. Delete the v1 records and unit, commit and push. Flux switches the unit when the v2 unit is registered.

A first production waits on v2: app-new creates staging only, v1's promotion command went with v1's edit commands, and swhurl-v2 promote reads production's records, so a first production has none to change.
