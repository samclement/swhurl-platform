What happens

  1. Creates the public repository {{ owner }}/<name> from the stack's template.
  2. Its first build checks the app and publishes ghcr.io/{{ owner }}/<name>.
  3. Opens a pull request here adding <name>/staging, set up from the app's swhurl.yaml.
  4. After you merge it, every push to the app's main deploys to staging.

The job page shows each step. Production comes later, with Promote to prod.
