Call this from my app

Before your app is created, in its swhurl.yaml:

calls: [{{ s.app }}]

Afterwards, your app page's Calls form, or:

make app-calls APP=<your app> ENV=staging ARGS="--add {{ s.app }}"

Then, in your code (the stack templates' helper):

service("{{ s.app }}").fetch("/")        // TypeScript
platform.call("{{ s.app }}", "/")        // Kotlin

Removing an app that others call is refused until those calls are removed; a first promotion waits for the apps it calls to be in production.
